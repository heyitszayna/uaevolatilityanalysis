# 📘 CODS 620 – Advanced Statistical Inference  
## Term Project: Statistical Analysis of the UAE Stock Market

This repository contains the materials submitted for the **CODS 620 (Advanced Statistical Inference)** term project. The project examines volatility dynamics in the UAE stock market using GARCH family models, Value-at-Risk estimation, and comparative analysis across two distinct periods (2001–2005 and 2020–2024).

### 📂 Contents
- `*.csv` — The four dataset files used in the analysis (ADX and DFM historical index data).  
  *Data sourced from Investing.com.*
- `uae_volatility_analysis.py` — Python script containing all preprocessing steps, model estimations, statistical tests, and figure generation.

This repository is private and is intended solely as documentation and backup for the course submission for **CODS 620 – Advanced Statistical Inference**.
